# README 界面图来源

这五张 PNG 来自 METIS v1.7 跨宿主工作台的真实本机页面，由独立的 Node/MCP 服务渲染，通过 headless 浏览器中的正常界面交互截图。未连接或操作用户正在使用的窗口。

演示模式与项目通过实际插件工具建立，示例 Markdown 文件实际写入、读回并提交。研究图中的 3/8 已交付对应这三份示例文件。截图里的需求和反馈文本处于输入草稿状态，未发送模型；没有额外生成 AI 回复。资料内容用于展示流程与交付交互。

- workflow.png：已保存的自定义模式与未发送的需求草稿。
- step-editor.png：当前步骤的目的、技能、提示词及禁止事项。
- skill-library.png：真实目录关键词检索和来源信息。
- research-overview.png：主阶段、文件记录与三维全景。
- step-feedback.png：选择步骤后填写针对性修改意见。
