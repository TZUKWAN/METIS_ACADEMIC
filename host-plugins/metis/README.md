# METIS

**把研究流程变成可以一起搭建、看见执行、持续修改的工作现场。**

METIS 将模式编排、科研技能、研究项目和交付物放在同一个离子回路工作台中。用自然语言和 AI 一起搭流程，也可以直接编辑每一步。

## 可以做什么

- **自己的研究模式**：自由增删、排序步骤，设置主要目的、交付内容、技能、步骤提示词和可选禁止事项。最后一步可选 Word、PPT、PDF、Markdown 等输出要求，Word 支持自然语言排版规定。
- **AI 与界面共同编辑**：共用同一份草稿，改动同步显示，保护手动修改；最后一次“保存并生效”。
- **具体技能，逐步加载**：检索现有科研技能目录中的具体技能，按需读取与绑定；运行到对应步骤再加载。资源固定版本并校验，依赖由宿主原生工具按需准备。
- **真实研究项目**：从已保存模式创建项目，一个文件夹可以绑定多个项目。旧项目保存流程与技能快照，新配置不会悄悄覆盖旧任务。
- **研究现场**：复用 DSH 版离子回路三维画布、主步骤与子动作、动态连线、跟随视角和真实调用记录。不会用虚构动作填充画面。
- **针对这一步修改**：选中步骤后直接给意见；返修交付后选择保留或重做后续成果。普通顺序执行不会每一步都强迫确认。
- **交付有依据**：检查实际文件存在、大小和摘要；开启达标循环时需要真实独立核验。没有检查不能自称通过。

## 宿主支持

| 能力 | DSH 现有版 | Codex 跨宿主版 | ZCode 跨宿主版 |
| --- | --- | --- | --- |
| 原有 DSH 插件 | 保持原样 | 不修改 DSH | 不修改 DSH |
| 模式、步骤、技能和共享草稿 | 原生 | 原生插件 + MCP | 原生插件 + MCP |
| 离子回路工作台 | 原生页面 | MCP Apps；不支持内嵌时本机工作台 | 支持 MCP Apps 时内嵌；否则本机工作台 |
| AI 原生文件、命令、搜索工具 | 原生会话 | 原生 Codex app-server 会话，也可用当前宿主主对话 | 当前 ZCode 原生主对话，使用插件工具 |
| 右侧工作台完整流式对话 | 原生 | Codex 原生会话 | 宿主消息桥接；主对话显示 AI 回复 |
| 独立达标核验 | 现有实现 | 真实 Codex 只读核验 | 可调用本机 Codex 只读核验；需要已安装并登录 Codex |
| 文档查看与编辑 | 现有实现 | MD/TXT/CSV/JSON 直接编辑，PDF 预览，Office 原文件下载后编辑 | 同左 |

MCP Apps 的展示由宿主决定，不会修改或注入宿主程序。原生宿主的模型、账号、审批和权限保持自己的规则；插件不复制凭据、不创建另一套 API Key 登录。原生权限请求必须由用户处理。

## 安装

需要 Node.js 22.19 或以上。整个 `host-plugins` 目录是本地插件市场；请保留隐藏的 `.agents`、`.zcode-plugin` 和 `metis/.codex-plugin` 等目录。

**Codex**

```powershell
codex plugin marketplace add "D:\路径\host-plugins"
codex plugin add metis@metis-local
```

也可以在 Codex 插件设置中添加此本地市场并安装 METIS。若当前会话尚未发现新工具，下次新建会话再使用；不需要修改系统提示词或模型配置。

**ZCode**

在插件市场添加本地 `host-plugins` 目录，安装并启用 **METIS**。支持命令的版本可使用 `/metis` 和 `/metis-config`。启用插件可能刷新关联会话，请在当前任务结束后操作。

在任意宿主对 AI 说：“打开 METIS”，或调用 `metis_open`。内嵌界面不可用时，打开工具返回的本机链接。ZCode 仍使用自己的主对话执行任务；开启达标循环时，`metis_step_check` 明确调用本机 Codex 作为独立只读核验器，主对话模型不变。

如宿主只能添加 MCP，选择 stdio：命令 `node`，参数为本目录下 `runtime/server.mjs` 的绝对路径，环境变量 `METIS_HOST=codex` 或 `zcode`。这是工具入口；技能与菜单入口需按宿主插件方式安装。

## 数据与安全

- 同机已有 `~/.dsh` 时，默认共用该目录中的已保存模式和技能。否则使用 `~/.metis`；可通过 **METIS_DATA_HOME** 指定目录。环境变量只影响插件进程。
- 跨宿主项目与会话保存在数据目录的 `metis-portable/` 中，**不会迁移或重写现有 DSH 研究项目**。跨宿主项目可由 Codex/ZCode 的 METIS 工具共同访问。
- 保存使用版本检查；另一宿主先保存时会保留当前草稿并提示协调，不静默覆盖。
- 删除项目仅删除项目记录，保留资料文件和其他项目。
- 本机工作台只监听 `127.0.0.1`，每次生成随机访问凭证；不对局域网开放。
- 研究技能初次读取可能下载固定 GitHub 版本；下载会校验 Git blob 摘要。只有被选择的资源会准备，不自动执行仓库代码或批量安装依赖。
- 独立核验只读取指定项目；同一文件摘要复用核验结果。原生自动续跑遇到没有步骤进展的完整轮次会停止，避免空转。

## 许可与边界

本包自写跨宿主代码采用 **Apache-2.0**。Apache-2.0 允许商业使用。第三方 React、Three.js、MCP SDK 许可见 `THIRD_PARTY_NOTICES.md`，科研技能保留各自上游许可。

发行包只带科研技能目录与资源摘要，**没有重新分发全部上游技能正文和脚本**，也不包含用户论文、配置、会话或登录信息。读取选定技能时再从固定源获取。

设置 Word/PPT 输出要求并不等于已经生成文件；实际生成仍由宿主原生工具和当前步骤绑定技能完成。本包不会伪造 Office 文件、核验结论、执行记录或进度。
