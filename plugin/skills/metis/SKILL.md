# METIS 研究工作流

驱动 `engine/`（METIS ACADEMIC 运行时）完成研究全流程：项目初始化 → 研究类型 → 工作流装配 → 动态 Skill/MCP 路由 → 任务执行 → 阶段验证 → 成文 → 交付。

## 调度纪律
- 工作流中每个任务的执行，优先派发 `metis-executor` 子智能体（用户无需另起 Agent）。
- 用户只在检查点做研究判断：选题定板、研究设计确认、结论把关、交付放行。
- 全程铁律：文献未核验不进参考文献；变量来自显式研究设计；fail-closed 不编造。
