## 可变步骤编排

- 每个模式独立配置步骤数量，保存范围为1–20步；不是所有模式固定十步。
- 支持在当前步骤后新增、复制当前步骤、删除、上移、下移。删除到空草稿后可以重新添加，空流程不能保存。
- 步骤左侧手柄支持拖动排序，插入线区分放在目标前后；宽面板上下拖动，窄面板横向步骤条左右拖动。键盘聚焦步骤或手柄后可按Alt+方向键移动，原上移/下移按钮保留并共用相同逻辑。
- 排序按稳定步骤ID移动完整对象，只更改steps数组顺序；技能绑定、阶段关联、主要目的、交付内容、技能、统一提示词、禁止/循环与兼容参数均保留，模式级技能列表也不重新计算。展示序号随顺序更新，当前选中步骤按ID跟随，当前编辑页签保留。
- 取消或原位放置不修改草稿，跨模式拖动不采用，拖动期间配置草稿变化会拒绝旧位置；切换模式/配置页、进入保存或打开模式菜单时清理拖动状态。排序只写已有本地草稿，“保存并生效”后才用于新会话，不发送模型请求或新增API调用。
- 历史模板保留读取兼容；当前自建模式不要求成果/研究范式分类，基础流程可自由增删，不限制为固定十步。
- 一次直接编辑一个步骤的主要目的、交付、技能和统一提示词；同一个模式Agent按配置顺序逐步加载，不把各步全文塞进总提示词。
- 引擎阶段关联是可选的，可一对多。编排步骤增删不会删除已有项目任务，也不等于引擎阶段自动完成。
- 只有精确匹配旧默认模板的配置会采用新版默认；用户已自定义的步骤和文字保留。
- 保存时暂时锁定编辑和模式切换，避免保存响应覆盖后续输入。旧后端尚未加载新能力时不向旧接口保存，以免丢失阶段关联字段。

## AI共创助手：DSH 原生会话

### 原生会话连接顺序修正（2026-11-02）

连接时先关闭目录订阅并置获取门闩，再调用`retain`。DSH会在`retainScope`中同步`publishRetention -> list.set`，默认列表source同步通知；退订晚于`retain`会在`owned`尚未赋值时重入自身。本版关闭该重入窗口，异步回调捕获自己的candidate，并在退出时只释放自身reference和状态订阅。

`reference.ready`并不必然表示成功打开：DSH对部分RemoteFailure只设置`openState=error/openError`。因此继续监听真实session snapshot，仅`open`时挂载正文，`error`显示实际原因，成功后清旧错误。失败面板直接给出阶段、原生code和message，避免只留下通用“无法连接”而需要反复展开。

本轮只读资料、压缩会话头和权限事件；未删除/重建映射或会话，不改DSH内部计数，不切换独立聊天或增加调用上限。上述是2026-11-02源码阶段记录；本轮已有真实隔离连接与完整模型/工具验证，不将历史未测试状态或隔离成功冒充现用desktop已迁移。

### 配置专用界面（2026-11-02）

助手直接编辑METIS的模式、步骤、技能和提示词，不要求选择研究工作区。原生Session所需的内部目录由服务提供，内部`workspaceId`只是编排状态键，不是让用户挑选文件夹。

- 空态、快捷建议、当前编辑对象与连接提示随版本化Editor一起加载；通过`conversation.content`的`views`局部槽显示配置空态，`hero=false`且使用embedded布局，不挂载通用品牌首页、项目目录选择或主会话导航。
- 实际消息和工具卡片仍由原生`conversation.session`渲染；输入、模型、停止、排队等仍为原生Composer。空白时保留原生会话生命周期/输入草稿持久化，不模拟聊天记录或“已连接”。
- 父客户端只持有真实SessionReference，接受`renderContent`；缓存的旧父组件通过原有子slot适配到同一配置界面，避免新旧组件混用时重新出现通用Hero。
- 元数据HTTP由Editor自持URL处理，保留query；状态读取优先POST携带标识，只有旧Host返回405时用保留完整query的GET兼容，不再捕获旧父模块丢参数的getJson。此兼容不发送模型请求。
- 右栏统一为64px标题/当前对象、真实状态点、紧凑可展开错误详情、居中配置建议及底部原生输入。移除重复顶部建议条和工程说明页脚；恢复后的状态错误会清除，错误时不假装持续连接。

当前已保存编排标识的只读元信息本身有效，未删除或重建该会话。现场缓存版本及本轮改动的运行、视觉效果尚未验收；开发工具没有调用Native API、模型、测试或主动重载界面。


- 右侧保留助手位置，嵌入原生 `conversation.content` Factory（`variant=embedded`，不带主会话Hero与导航），以显式 `SessionProvider` 绑定真实 DSH Session；正文、推理/工具卡片、流式回复、输入、停止、排队、模型/思考档位和会话记录由 DSH 自己处理。
- 已撤掉助手自建的 `llm.prepareCall` 循环、最多三次模型请求、两轮读取、合计60k披露预算、五分钟整体等待，以及最近6轮/40条的私有聊天截断。METIS 不另外规定模型请求次数；DSH 自身的上下文、权限、模型服务与取消规则照常适用。
- 不再解析 `metis-read`/`metis-edit` 文本代码块伪装工具。内部隐藏预设 `metis.composer` 注册真正的 `metis_config_read` 与 `metis_config_edit`，由原生 Agent loop 执行并留下原生调用/结果事件。该预设不会混入研究模式菜单，也不匹配研究模式的 `metis-*` 版本路由。
- 工作流、全部模式和技能共用一段原生编排对话。可连续讨论、读取实际配置、检索/绑定技能、增删排序步骤、修改提示词及参数、创建/安装/修改/归档/恢复技能与模式。具体操作规范通过工具按需读取，不把所有操作细节与技能正文塞进初始提示词。

- 工具将多次编辑累计到一份可审阅提案，后续工具读取可见此提案草稿。工作台显示真实“修改前/修改后”，待原生轮次空闲后可应用；应用前重新核对提案版本和人工草稿，正式生效仍需“保存全部配置”。可以撤销最近一次应用，存在后续手动编辑时拒绝覆盖。

- 快捷问题只填入当前原生输入草稿，不自动发送。新对话创建新的真实 DSH Session，不删除旧会话。原生会话ID与提案保存在 `<DSH_HOME|~/.dsh>/metis-composer-workspaces/<scope>/<workspaceUUID>.json`，浏览器记录当前workspace UUID；消息历史沿用DSH自己的Session存储。恢复当前助手绑定依赖这个浏览器记录仍在；清理存储或更换浏览器来源后不会猜测改绑旧会话。

## 技能来源与配置保存

科研技能库已接入给定10仓库及第一层明确引用来源的实际入口索引，数量/commit/只读项见preset/library。技能库和步骤绑定区支持关键词、来源过滤与每页12项；可从技能详情直接绑定当前步骤。原文每次4000字符，资源清单分页，下一片段/下一页均由用户或助手按需请求；编排助手不会因选中某项就收到其全部正文。

运行时加载一个步骤控制器，再经metis_library逐项读取本步绑定的候选，不把本步所有技能一次注入上下文。来源、许可文件、上游自报评估、依赖提及和METIS未实测状态分别展示；MCP/CLI/浏览器/凭据依赖不会在入库时自动安装或配置。少数YAML清单/格式无效入口仅供查看，不能假装可调用。原文中的权限/子Agent/安装要求不能覆盖用户当前指令。

模式选择区支持直接管理：分组菜单可搜索模式，每项右侧可删除，菜单底部及选择框旁均有“新建模式”。手动新建不依赖模型，可填写名称、说明、成果与范式，选择复制任意现有模式的当前草稿（完整步骤、技能、提示词、默认参数），或使用基础模板。模式ID自动生成；创建后进入工作流继续编排。

模式右侧的编辑按钮，以及“模式配置”页的“编辑名称和说明”，均可直接打开手动表单。原名称与说明会回填；仅提交这两个字段，ID、步骤和技能继续保留。名称须非空且不超过120字，说明不超过3000字；没有修改时不发请求，取消或失败不替换草稿。

模式菜单左侧手柄支持在同一成果分组内拖动排序，放置线区分目标前后；键盘聚焦手柄后可用Alt+↑/↓。搜索结果仍按完整分组中的真实位置移动，组间不改变成果类型。取消拖动、放回原位置均不提交；拖动期间草稿变化会拒绝采用旧位置。后端一次校验完整活动模式排列，再更新整数order，归档不参与排序。改名、改说明或排序会保留当前正在编辑的步骤及页签，统一保存后生效。这些手动操作没有模型调用。

删除有明确的模式名称和步骤数量确认，采用现有归档机制；“模式配置”的已归档列表可直接恢复。删除最后一个模式后仍能新建或恢复。新增、删除、恢复都会合并其他模式未保存的步骤进入全局草稿，失败不替换草稿；统一点击“保存全部配置”后才更新新会话入口。已有会话继续走固定版本恢复通路，历史版本和资源不随模式删除而清理。

安装支持用户消息中提供的本地技能根目录、公开GitHub仓库/分支/子目录，或此前已保存的安装来源；GitHub固定到实际commit并核对文件哈希。识别SKILL.md，或SKILL.yaml+INSTRUCTIONS.md，并保留附属资源及来源入口原文。每包128个文件、单文件4MiB、总计20MiB；不接受越界路径、链接、子模块、未展开的Git LFS指针与凭据文件。有效字段采用常见标量frontmatter，不支持的字段结构明确报错；其他元数据保留在来源原文中，不借此增加Agent工具权限。

技能文件会先暂存到内容寻址包，配置保存后才成为METIS活动技能。安装器不执行来源包中的脚本、不安装Python/npm等运行依赖。正文和文本资源可由助手修改；二进制资源可以随包导入，目前不通过聊天直接生成或编辑二进制内容。未绑定的技能可在技能库安排到步骤，真实加载使用原生skill资源目录。

新工作区文件是`<DSH_HOME|~/.dsh>/metis-composer-configuration.json`，资源位于`metis-composer-packages/<sha256>/files/`。旧profile文件保留兼容读取，不会在打开页面时直接迁移写入。保存采用版本检查、写锁和原子文件替换；定义更新失败尝试恢复旧版本，已有Agent使用自己的技能/资源快照。

## 会话版本保护

新会话记录固定配置ID；模式、Persona、已编译步骤、技能正文和资源版本保存在`<DSH_HOME|~/.dsh>/metis-session-versions/`。保存工作区只改变以后通过当前模式入口新建的会话，旧会话按原ID/保护绑定恢复，不重新读取最新流程或技能正文。版本缺失/损坏会明确失败，不自动改成最新版。

“会话版本”页分页读取真实会话元数据，可查看固定声明、来源和异常。已有运行中旧Agent会尝试从真实组成建立保护记录；cold旧会话若没有历史记录，无法推断最初配置，默认不自动恢复。用户必须先查看具体版本，再明确确认保护基线；基线和原始记录分别标识，已绑定版本不能通过配置提案改写。

继续研究保留现有固定版本，新建研究与工作台新建会话使用当前模式入口；具名空白复用不会因配置更新自动升版。新建菜单只显示当前版本，历史定义保持可恢复，不把所有版本挤进模式菜单。版本和资源不自动删除。

这不冻结DSH程序、插件代码、帐号密钥、时钟和项目研究文件。旧记录缺少原始证据时不能宣称已找回历史，相关运行行为仍未实测。

## 项目内研究对话与单步返修（2026-11-05）

研究项目右侧常驻同一项目原生DSH会话，可以直接输入消息；沿用DSH模型、权限、流式消息、工具卡片、停止与历史，不另做简化聊天。空会话显示研究入口，不再要求选择工作区。切换项目按各自sessionId保留草稿，不共享会话或新开会话替代。

展开一个步骤，研究助手标题下会显示正在查看的步骤。直接输入修改意见即可。每条消息在发送时绑定项目、固定版本和步骤，随后切换步骤也能继续处理原意见。收起步骤可回到整个项目的讨论。点击“修改这一步”会聚焦对话输入框。

助手先归档并修改当前步骤，沿用它的技能、提示词和验收要求。交付后，如果还有后续步骤，对话中会出现选择。

- “保留后续结果”保留已有交付。
- “重做后续步骤”从下一步开始重做，采用刚交付的修订结果。

后续尚未开始时可选“暂不继续”或“继续后续步骤”。最后一步交付即完成。若仍不满意当前步骤，可以直接继续提意见，后续选择以最新一次交付为准。重开项目会恢复待选择状态。

返修前保存已登记交付记录与当前可读文件的真实字节，步骤内“历史交付”可查看及下载。文件早已缺失/已变化/为链接时如实记录，不能凭空恢复原提交版本。目录保留真实副本与路径，不复制链接目标。每次归档最多4096文件/512MiB、单文件128MiB；超过边界则返修不启动、不重置步骤。历史独立存于DSH_HOME/metis-project-revisions，固定模式/技能/提示词快照及旧会话配置不被返修改写。
