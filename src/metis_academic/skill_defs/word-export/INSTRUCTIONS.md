# word-export

Word 生成

从当前步骤的“最终交付设置”读取客户选择的 Word 格式和自然语言排版要求。不要要求客户逐项填写字体、字号、学位层级、基金类别或目标期刊。
若当前步骤没有最终交付设置，按本步明确的交付内容和排版要求处理；不为查找格式而预加载其他步骤。

先区分正文、各级标题、页面、段落、脚注等用途，再将自然语言落实到真实 Word 样式或节设置。可生成真实 template-spec.yaml 后导出，也可使用已绑定的成熟 Word 技能、python-docx 与 OOXML；优先采用不接管桌面的文件 API。

基础 parse_nl_requirements 只能识别少数正文字体、字号、行距，不能替代对整段要求的理解。中文字体需落实到 w:rFonts 的 eastAsia 设置；不能只设西文字体或把标题字体误当正文。复杂表格、脚注或模板超出基础生成器能力时，使用真实可用的文档技能或 Word API 补齐，不用占位段落冒充表格或忽略排版要求。

生成真实 .docx 文件后回读核对结构、实际指定的样式和必要内容，再报告交付路径。不得把排版要求原文写进文档当成已完成排版，也不得改扩展名伪装 Word。加载、准备资源和依赖安装不代表文件已经生成；实际失败如实报告。
